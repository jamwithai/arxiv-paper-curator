# 10 周课程路线

这份路线固定学习顺序与每周验收边界，但不提供实现答案。每周 6 次学习；除 W10D05 的 180 分钟独立终验外，每次约 60–90 分钟。只有拿到对应证据后才进入下一周。

## Week 1 — HTTP、FastAPI 与内存 CRUD

**周目标：** 能从 HTTP 契约出发，独立实现带 Pydantic 验证、统一状态码和内存存储的任务 CRUD API。

**周验收：** 不看示例完成一组 CRUD 路由；行为测试通过，并能解释请求、响应、JSON、状态码、路由匹配和 OpenAPI 的关系。

| Session | Focus | Evidence |
|---|---|---|
| W01D01 | 第一个可验证的 liveness 契约 | 行为与 OpenAPI 测试通过；口头解释 HTTP 响应 |
| W01D02 | 路径、查询参数与类型转换 | 成功和验证失败用例通过 |
| W01D03 | Pydantic 请求/响应模型 | 输入约束、输出过滤和 schema 证据 |
| W01D04 | 状态码、业务错误与默认 404 | 成功、缺失和冲突行为测试 |
| W01D05 | 内存任务 CRUD 与依赖注入起点 | 完整 CRUD 测试，不使用数据库 |
| W01D06 | 独立重建、OpenAPI 检查与周复盘 | 周验收记录和无笔记解释 |

**周验收：** 在真实测试数据库中创建、读取和分页资源；迁移可升级和回退，并能解释异步会话生命周期与事务边界。

| W02D03 | ORM 模型与 UTC 时间 | 约束、唯一性和时区测试 |

## Week 10 — 质量门与独立实战

**周目标：** 用测试、运行观察、解释和限时重建证明能力能够脱离课程答案迁移到新问题。

**周验收：** 按下方终验契约，在 180 分钟内完成指定行为并运行给定测试；对未完成项、提示使用和设计取舍如实报告。

### 3 小时独立实战契约

**计时：** 从首次查看验收题和测试开始，至最后一次测试命令结束，共 180 分钟；W10D04 的概念答辩不计入这 180 分钟。

**允许使用：** 给定的 `pyproject.toml`、空应用包、行为测试、Python/FastAPI 官方文档和本地编辑器。允许使用测试提供的内存 repository 与确定性假检索器。禁止查看本课程实现、三级提示、既有项目源码或生成完整实现的 AI 输出。

**必须实现的端点与行为：**

- `POST /api/v1/auth/register`：创建用户；重复 email 返回冲突；密码不以明文存储；
- `POST /api/v1/auth/login`：正确凭据返回短期 access JWT；错误凭据返回统一认证错误；
- `GET /api/v1/users/me`：有效 bearer token 返回当前用户；缺失、无效或过期 token 被拒绝；
- `POST /api/v1/knowledge-bases` 与 `GET /api/v1/knowledge-bases/{id}`：创建和读取仅属于当前用户的知识库；
- `POST /api/v1/knowledge-bases/{id}/documents`：登记一个经过文件名、大小、MIME 与 PDF 魔数校验的模拟上传；
- `POST /api/v1/knowledge-bases/{id}/search`：调用给定的确定性假检索器，只返回该用户与知识库的数据；
- `POST /api/v1/knowledge-bases/{id}/ask`：基于假检索结果返回答案和结构化 citations；无结果时明确拒答；
- 未知资源返回 404，重复资源返回 409，验证错误、认证错误和跨用户访问具有可判定响应。

**必测场景：** 成功注册/登录/当前用户；重复 email；错误与过期令牌；两个用户之间的知识库、文档、检索和问答越权；合法与伪装 PDF；有结果的结构化引用；无结果拒答；OpenAPI 中所有必修端点可见。

**评分：** 给定终验测试全绿且认证、跨用户隔离、PDF 边界和引用四个关键分组均全绿，判定 `pass`；关键分组全部通过但其他测试有失败，判定 `partial`；任一关键分组失败，判定 `fail`。时间结束立即停止，保留失败输出并列出所有未完成项，不延时修补。

## 进阶扩展（不阻塞核心结业）

完成 Week 10 后，可按证据选择以下方向，而不是在主线中提前增加范围：

- 刷新令牌轮换、哈希存储与注销撤销；
- 用户反馈和知识库重建索引端点；
- 从 `BackgroundTasks` 迁移到持久任务队列和多 worker；
- 团队角色、公开分享和更细授权；
- LangGraph Agentic RAG：护栏、文档评分和查询改写；
- 云主机、TLS、指标系统或 Kubernetes 部署。
